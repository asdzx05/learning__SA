# Разбор open-source проектов: модель веток и релизов

| Проект | Описание |
|---|---|
| **Medusa** | Open-source платформа для создания интернет-магазинов. Предлагает базовую логику в виде модулей.<br><br>Модель веток идёт по шаблону «тип/описание». Все изменения вливаются в основную ветку разработки — `develop`. Релиз помечается git-тегами «имя пакета»@версия пакета, формат версии пишут по SemVer. |
| **Kong** | API Gateway. Берёт на себя «общее» для всех сервисов: маршрутизацию, проксирование, балансировку нагрузки, аутентификацию, rate limiting, кэширование, health-checking. Расширяется плагинами.<br><br>Модель веток идёт по шаблону «тип/описание». Все изменения пушатся в `master`. Есть долгоживущие ветки релиза. Фиксы переносят в старые версии через backport. Релиз помечается git-тегами только с номером версии. |
| **Plane** | Открытый инструмент управления проектами (project management). По сути аналог Jira, который можно поставить себе на сервер. Команды используют его, чтобы вести задачи и планировать работу.<br><br>Модель веток идёт по шаблону «тип/имя». Все изменения пушатся в `master`. В коммите прописывают ссылку на тикет в трекере. Релиз помечается git-тегами `vX.Y.Z`. |
| **Общее (все 3)** | Во всех трёх проектах подключены ИИ-агенты для работы. |
