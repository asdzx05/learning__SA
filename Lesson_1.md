### ОПИСАНИЕ СИСТЕМЫ продукта "ОСТРОВОК"

### 1. Booking Service

| Поле | Значение                                                                                                                                                                                        |
|---|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Название системы | Booking Service                                                                                                                                                                                |
| Категория | System of Record (SoR)                                                                                                                                                                          |
| Роль в бизнесе | Центральная система жизненного цикла бронирования: создание брони, статусы, отмены, ваучеры, связь с оплатой и доступностью номера.                                                             |
| Входящие потоки данных | Заявка на бронирование от Web/Mobile (REST/JSON), статус оплаты от Payment  (REST), результат проверки наличия от Inventory Service (REST), статус роверки от Fraud, информация об отеля от MDM |
| Исходящие потоки данных | Запрос на холд номера в Inventory (REST), платежное поручение в Payment  (REST), события брони (оплаты) в Message Broker (Kafka), выгрузка заказов в DWH (ETL), запрос Fraud проверки.          |

### 2. Inventory Service
| Поле | Значение |
|---|---|
| Название системы | Inventory Service |
| Категория | System of Record (SoR) |
| Роль в бизнесе | Хранит и проверяет доступность номеров: можно ли показать номер в выдаче и можно ли забронировать его сейчас. |
| Входящие потоки данных |  запрос холда номера от Booking Service (REST), обновления цен от внешний поставщиков (REST), справочник отелей из MDM. |
| Исходящие потоки данных | Ответ о наличии номеров в Booking Service(REST), подтверждение/отказ холда в Booking Service (REST). |

### 3. MDM

| Поле | Значение |
|---|---|
| Название системы | MDM |
| Категория | System of Record (SoR) |
| Роль в бизнесе | Единый источник мастер-данных по отелям: название, адрес, координаты, фото, описание, типы номеров, удобства. |
| Входящие потоки данных | Карточки и изменения отелей из ЛК партнеров /  загрузки от внешних поставщиков (API). |
| Исходящие потоки данных | Контент отелей в Search (Kafka), выгрузка справочников в DWH (sftp), информация об ID отеля в booking service (Kafka), полный справочник информации об отеле в Inventory service. |

### 4. Payment

| Поле | Значение |
|---|---|
| Название системы | Payment |
| Категория | System of Record (SoR) |
| Роль в бизнесе | Обрабатывает оплату, возвраты, подтверждение платежа и связь с внешними платежными провайдерами. |
| Входящие потоки данных | Платежное поручение от Booking Service (REST), запрос на возврат по отмененной брони (REST). |
| Исходящие потоки данных | Статус оплаты в Booking Service (REST). |

### 5. DWH 

| Поле | Значение |
|---|---|
| Название системы | DWH |
| Категория | System of Insight (SoI) |
| Роль в бизнесе | Собирает исторические данные для отчетности: бронирования, оплаты, конверсия, источники трафика, финансы. |
| Входящие потоки данных | Ночные выгрузки из ERP, MDM, CRM (SFTP). |
| Исходящие потоки данных | Витрины данных для BI Platform (SQL) |

### 6. BI Platform

| Поле | Значение |
|---|---|
| Название системы | BI Platform |
| Категория | System of Insight (SoI) |
| Роль в бизнесе | Дашборды и отчеты для менеджмента: выручка, конверсия, отмены, маржинальность, загрузка направлений. |
| Входящие потоки данных | Витрины данных из DWH (SQL). |
| Исходящие потоки данных | Дашборды и KPI для менеджмента, регулярные отчеты для финансов и продуктовых команд. |

### 1. ДБО

| Поле | Значение |
|---|---|
| Название системы | ДБО |
| Категория | System of Engagement (SoE) |
| Роль в бизнесе | Интерфейс клиента: вход в банк, просмотр счетов, создание платежей, получение статусов и уведомлений. |
| Входящие потоки данных | Действия клиента; уведомления и статусы операции от Notification; данные счетов и клиента через API Gateway. |
| Исходящие потоки данных | HTTPS/API-запросы через WAF: вход, просмотр данных, создание платежа. |

### 2. WAF

| Поле | Значение |
|---|---|
| Название системы | WAF |
| Категория | Security / Integration |
| Роль в бизнесе | Защищает внешний контур банка от вредоносных HTTP/API-запросов. |
| Входящие потоки данных | HTTPS/API-запросы из ДБО. |
| Исходящие потоки данных | Разрешенные запросы в API Gateway |

### 3. API Gateway

| Поле | Значение |
|---|---|
| Название системы | API Gateway |
| Категория | Integration |
| Роль в бизнесе | Маршрутизирует запросы из ДБО во внутренние системы банка. |
| Входящие потоки данных | Разрешенные запросы от WAF. |
| Исходящие потоки данных | Запрос токена в ЕСА/IAM; запросы в MDM, АБС/Core Banking и Payment Hub. |

### 4. ЕСА / IAM

| Поле | Значение |
|---|---|
| Название системы | ЕСА / IAM |
| Категория | Security / Integration |
| Роль в бизнесе | Проверяет, кто клиент, и выдает токен доступа для работы с банковскими API. |
| Входящие потоки данных | Запрос на аутентификацию или проверку токена от API Gateway. |
| Исходящие потоки данных | Результат проверки, токен доступа, информация о правах клиента. |

### 5. MDM

| Поле | Значение |
|---|---|
| Название системы | MDM |
| Категория | System of Record (SoR) |
| Роль в бизнесе | Единый источник мастер-данных клиента: ФИО, контакты, документы, идентификаторы. |
| Входящие потоки данных | Запрос клиентских данных от API Gateway; изменения клиентских данных из банковских процессов. |
| Исходящие потоки данных | Клиентские данные в ДБО через API; выгрузка клиентских данных в DWH/BI. |

### 6. АБС / Core Banking

| Поле | Значение |
|---|---|
| Название системы | АБС / Core Banking |
| Категория | System of Record (SoR) |
| Роль в бизнесе | Операционное ядро банка: счета, балансы, проводки, списания и зачисления. |
| Входящие потоки данных | Запросы счетов и балансов от API Gateway; команда списания/проводки от Payment Hub. |
| Исходящие потоки данных | Данные счетов и балансов в ДБО через API Gateway; операционные данные в DWH/BI. |
